# 🚀 Atharv's Interactive Portfolio App

A sleek, dark-themed interactive resume and portfolio application built entirely with **Flutter** and **Dart**. This mobile application serves as a dynamic showcase of my skills, projects, and academic journey as a Computer Science (Core) student.

## ✨ Features

* **Custom UI/UX:** Features a sleek `0xFF0D0D0D` dark background with modern "Glassmorphism" effect cards.
* **Dynamic Animations:** Includes smooth entry animations and interactive scrolling sliders.
* **Custom Branding:** Integrated a custom generated app icon and responsive splash screen.
* **Organized Navigation:** Implemented a custom side drawer and bottom navigation bar for seamless routing.
* **Project Showcase:** A dedicated screen detailing technical projects and hackathon builds.

## 💻 Tech Stack
* **Framework:** Flutter
* **Language:** Dart
* **UI Design:** Custom Dark Theme, BackdropFilter (Glassmorphism)
* **Key Packages:** `flutter_launcher_icons`, `cupertino_icons`

## 🛠️ How to Run This Project

To clone and run this application on your local machine, you'll need [Git](https://git-scm.com) and [Flutter](https://flutter.dev/docs/get-started/install) installed. From your command line:

```bash
# Clone this repository
$ git clone [https://github.com/YOUR_USERNAME/flutter-portfolio-app.git](https://github.com/YOUR_USERNAME/flutter-portfolio-app.git)

# Go into the repository
$ cd flutter-portfolio-app

# Install dependencies
$ flutter pub get

# Run the app
$ flutter run
